# 구글 자동 시세 · 자동 백업 설치 (처음 한 번, 약 5분)

앱이 현재가·환율을 자동으로 받고, 입력한 내용을 내 구글 드라이브에 자동 백업하도록 **내 구글 계정**에 작은 스크립트를 하나 설치합니다. 비용은 없습니다.

## 1. 스크립트 만들기
1. [구글 스프레드시트](https://sheets.google.com)에서 **빈 스프레드시트**를 새로 만듭니다. 이름은 `내 포트폴리오 시세` 정도로 짓습니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 편집기에 있는 기본 코드를 모두 지우고, 이 폴더의 **`Code.gs` 내용 전체**를 붙여 넣은 뒤 저장(💾)합니다.

## 2. 설치 실행
1. 위쪽 함수 선택 칸에서 **`setup`**을 고르고 **실행**을 누릅니다.
2. 권한 요청이 뜨면 본인 계정을 고르고 **허용**합니다. "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 누릅니다. 본인이 만든 스크립트라서 나오는 안내입니다.
3. 시트에 **「설정」 탭**이 생기고, 그 안에 **토큰**이 적혀 있습니다.

## 3. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 유형 선택(⚙)에서 **웹 앱**을 고릅니다.
3. **실행: 나**, **액세스 권한: 모든 사용자**로 설정하고 **배포**를 누릅니다.
4. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

> 액세스 권한을 "모든 사용자"로 해도 **토큰이 없으면 아무것도 조회할 수 없습니다.** 토큰은 다른 사람에게 알려 주지 마세요.

## 4. 앱에 연결
앱의 **설정 → 구글 자동 시세**(또는 처음 시작하기 4단계)에서 URL과 토큰을 붙여 넣고 **연결 테스트** → **저장**을 누릅니다.

## 알아 둘 것
- 시세는 구글 `GOOGLEFINANCE` 기준입니다. 장중에는 최대 약 20분 늦고, 장 마감 후에는 종가입니다. 앱의 자동 갱신 주기(기본 15분)까지 더하면 화면에는 최대 30분 남짓 늦게 보일 수 있습니다.
- 국내 종목은 앱에서 **종목코드(6자리)**를 넣어야 자동 시세가 붙습니다. 코드가 없으면 직접 입력한 현재가를 씁니다.
- 새로 추가한 종목은 구글이 처음 계산하는 데 몇 초 걸려 "대기 중"으로 나올 수 있습니다. 다음 갱신 때 들어옵니다.
- 자동 백업은 드라이브의 **「내 포트폴리오 백업」 폴더**에 저장됩니다. `portfolio-backup.json`이 최신본이고, 날짜별 사본은 최근 30일치만 남깁니다. 시트의 **「보유현황」 탭**에서 보유 종목과 예수금을 표로 볼 수 있습니다.
- 새 폰에서는 앱 설치 → 같은 URL·토큰으로 연결 → **설정 → 백업·복원 → 구글에서 복원**을 누르면 됩니다.
- 토큰이 새어 나간 것 같으면 Apps Script에서 **`resetToken`**을 실행하세요. 새 토큰이 만들어지고, 이전 토큰은 더 이상 쓸 수 없습니다.
- `Code.gs`를 고쳤다면 **배포 → 배포 관리 → 편집(연필) → 버전: 새 버전 → 배포**를 눌러야 반영됩니다. URL은 바뀌지 않습니다.
